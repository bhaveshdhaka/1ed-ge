# Pipeline — prod / test separation (implementation plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Codify the prod / test separation into a set of guard scripts so test data never lands on prod, prod data never lands on test, and de-indexing is test-only.

**Architecture:** Each worktree's `.env` declares `SITE_ENV=prod|test`. Every script that deploys, syncs, seeds, or verifies sources `scripts/lib/env.sh` and calls `require_env <expected>` — wrong env exits non-zero with a loud message. Per-env deploy scripts replace the ambiguous `deploy.sh`. The preprod branch holds the preprod-only files (`.env`, `nginx/test.1ed.ge.conf`, the seed-review date tweak) explicitly; `sync-from-prod.sh` stashes them across merges.

**Tech Stack:** bash (env, deploy, sync, verify scripts), Node (seed scripts, test runner), Nginx (test vhost), Astro 5 (the app), Tailwind v4.

## Global Constraints

- **Env-typing:** `SITE_ENV` ∈ {`prod`, `test`} declared in each worktree's gitignored `.env`. Both envs use the same scripts; the `.env` decides which is which.
- **No silent failures.** Every guard exits non-zero with a 1-3 line message naming the script, the expected env, the actual env, and the worktree path.
- **Preprod's `.env`, `nginx/test.1ed.ge.conf`, and the date tweak in `scripts/seed-review.mjs` are preprod-only.** `sync-from-prod.sh` stashes them across the merge; `sync-to-prod.sh` allows them implicitly via the existing allowlist (none of them match the allowlist — they never sync to main).
- **Test de-index layers (all 4 stay):** nginx `auth_basic`, `add_header X-Robots-Tag "noindex, nofollow" always`, `robots.txt` 200 returning `Disallow: /`, `Base.astro` meta `noindex,nofollow` driven by `process.env.SITE_NOINDEX === '1'`.
- **Preprod has no cron.** Content is human-committed on the preprod branch. The 30-min autosave cron + the 8h market-news cron stay **prod-only**.
- **Preprod runs `node dist/server/entry.mjs` directly on port 4323** (no docker). The `docker compose` setup stays prod-only.
- **Commit prefixes:** `feat:` / `fix:` / `chore:` / `docs:`. One logical change per commit. The 02:00 autosave cron may sweep uncommitted edits — commit promptly.

- [ ] **Step 1: Write `scripts/lib/env.sh`**

```bash
#!/usr/bin/env bash
# env.sh — the env-typing contract. Source this from every pipeline script.
#
# Reads the worktree's .env (gitignored) and exposes:
#   $SITE_ENV     "prod" or "test"
#   $SITE_URL     e.g. https://1ed.ge or https://test.1ed.ge
#   $SITE_PORT    e.g. 4321 (prod) or 4323 (test)
#   $SITE_NOINDEX "1" on test (noindex meta + headers), "0" on prod
#
# Use `require_env prod` (or `test`) at the top of any script that
# must run only in that env. Mismatched envs exit non-zero with a
# loud message — no silent wrong-env deploys.

set -euo pipefail

_ENV_LOADED=0

load_env() {
  if [ "$_ENV_LOADED" = 1 ]; then return 0; fi
  if [ -z "${SITE_ENV:-}" ]; then
    local env_file
    env_file="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)/.env"
    if [ -f "$env_file" ]; then
      set -a
      # shellcheck disable=SC1090
      . "$env_file"
      set +a
    fi
  fi
  # SITE_NOINDEX is derived; .env may override
  if [ -z "${SITE_NOINDEX:-}" ]; then
    case "${SITE_ENV:-}" in
      test) SITE_NOINDEX=1 ;;
      prod) SITE_NOINDEX=0 ;;
      *)    SITE_NOINDEX=0 ;;
    esac
  fi
  _ENV_LOADED=1
}

require_env() {
  local expected="$1"
  load_env
  local actual="${SITE_ENV:-<unset>}"
  local here
  here="$(pwd)"
  if [ "$actual" != "$expected" ]; then
    echo "✗ refusing: this script requires SITE_ENV=$expected" >&2
    echo "  but the worktree's .env says SITE_ENV=$actual" >&2
    echo "  worktree: $here" >&2
    echo "  fix: edit .env, or run from the $expected worktree" >&2
    exit 1
  fi
}

env_url()    { load_env; echo "${SITE_URL:-}"; }
env_port()   { load_env; echo "${SITE_PORT:-}"; }
env_noindex(){ load_env; echo "${SITE_NOINDEX:-0}"; }
```

import { spawnSync } from 'node:child_process'
import path from 'node:path'
import { fileURLToPath } from 'node:url'

const __dirname = path.dirname(fileURLToPath(import.meta.url))
const ROOT = path.join(__dirname, '..')
const SCRIPTS = path.join(ROOT, 'scripts')

const run = (cmd, args = [], env = {}) => {
  const r = spawnSync(cmd, args, {
    cwd: ROOT,
    env: { ...process.env, ...env },
    encoding: 'utf8',
    timeout: 15_000,
  })
  return { stdout: r.stdout ?? '', stderr: r.stderr ?? '', code: r.status ?? -1 }
}

const ok = (cond, label) => {
  if (cond) { console.log(`  ✓ ${label}`); return true }
  console.log(`  ✗ ${label}`); return false
}

const test = (label, fn) => {
  console.log(`\n${label}`)
  try {
    const okCount = fn()
    if (okCount > 0) pass++; else fail++

    console.log(`  ✗ threw: ${e.message}`)

```bash
#!/usr/bin/env bash
# sync-from-prod.sh — main → preprod sync.
#
# The opposite of sync-to-prod.sh. Pulls main's code into the preprod
# worktree, preserving the preprod-only files:
#   .env
#   nginx/test.1ed.ge.conf
#   scripts/seed-review.mjs (the date tweak)
#
# No allowlist — preprod is a superset of prod (it has prod code plus
# its own filler content). The sync is additive.
#
# Usage:
#   bash scripts/sync-from-prod.sh           # fetch + merge (fails on conflict)
#   bash scripts/sync-from-prod.sh --dry-run # show what would merge, do nothing
set -euo pipefail
cd "$(dirname "$0")/.."
source scripts/lib/env.sh
require_env test

branch=$(git rev-parse --abbrev-ref HEAD 2>/dev/null || echo "")
if [ "$branch" != "preprod" ]; then
  echo "✗ refusing: this script must run on the preprod branch (got: ${branch:-<no git>})" >&2
  exit 1
fi

DRY_RUN=0
for arg in "$@"; do
  case "$arg" in
    --dry-run) DRY_RUN=1 ;;
    -h|--help)
      sed -n '2,18p' "$0"
      exit 0
      ;;
    *) echo "unknown arg: $arg" >&2; exit 2 ;;
  esac
done

# Preprod-only files: preserve across the merge
PREPROD_ONLY=(
  ".env"
  "nginx/test.1ed.ge.conf"
  "scripts/seed-review.mjs"
)

# Find a worktree-local reference for main. /root/1ed.ge is the prod worktree
# (the .git/worktrees/* pointer in preprod confirms it shares the repo).
PROD_WORKTREE="/root/1ed.ge"
if [ ! -d "$PROD_WORKTREE/.git" ] && [ ! -f "$PROD_WORKTREE/.git" ]; then
  echo "✗ refusing: prod worktree not found at $PROD_WORKTREE" >&2
  echo "  this script syncs from the prod worktree path; pass the correct path." >&2
  exit 1
fi

echo "── main → preprod sync ──────────────────────────────────────────"
echo "preprod HEAD: $(git rev-parse --short HEAD)"
echo "main HEAD:    $(cd "$PROD_WORKTREE" && git rev-parse --short main)"
echo

# 1. Stash preprod-only files so the merge doesn't conflict
echo "→ stashing preprod-only files:"
for f in "${PREPROD_ONLY[@]}"; do echo "    $f"; done
git stash push -m "preprod-only: $(date -u +%FT%TZ)" -- "${PREPROD_ONLY[@]}"

# 2. Fetch main from the prod worktree
echo "→ fetching main from $PROD_WORKTREE"
git fetch "$PROD_WORKTREE" main

# 3. Compute the diff for the report
mapfile -t CHANGED < <(git diff --name-only HEAD FETCH_HEAD)
if [ ${#CHANGED[@]} -eq 0 ]; then
  echo "✓ no changes to sync (preprod ≡ main)"
  git stash pop >/dev/null
  exit 0
fi
echo "→ incoming: ${#CHANGED[@]} files"
for f in "${CHANGED[@]:-}"; do echo "    $f"; done
echo

if [ "$DRY_RUN" = 1 ]; then
  echo "(dry-run — nothing applied)"
  git stash pop >/dev/null
  exit 0
fi

# 4. Merge
echo "→ merging main into preprod"
if ! git merge --no-ff -m "sync: bring main to preprod ($(printf '%d' "${#CHANGED[@]}") files)" FETCH_HEAD; then
  echo
  echo "✗ merge conflict — aborting" >&2
  git merge --abort || true
  git stash pop >/dev/null || true
  exit 1
fi

# 5. Restore preprod-only files. If the pop conflicts (e.g. main also
# touched scripts/seed-review.mjs), prefer the preprod version.
if ! git stash pop >/dev/null 2>&1; then
  echo "! stash pop conflicted on a preprod-only file — using preprod's version"
  for f in "${PREPROD_ONLY[@]}"; do
    if git ls-files --error-unmatch "$f" >/dev/null 2>&1; then
      git checkout --theirs -- "$f" 2>/dev/null || true
      git add "$f" 2>/dev/null || true
    fi
  done
  git stash drop >/dev/null || true
fi

echo
echo "✓ synced. review, then run:"
echo "    cd $PROD_WORKTREE && bash scripts/deploy-prod.sh   # if you want to push back to prod"
echo "    bash scripts/deploy-test.sh                          # to restart the preprod"
```

```bash
#!/usr/bin/env bash
# verify-env.sh — assert the running env matches its declared type.
# Usage: bash scripts/verify-env.sh [prod|test]   (defaults to $SITE_ENV)
set -euo pipefail
cd "$(dirname "$0")/.."
source scripts/lib/env.sh
load_env

expected="${1:-$SITE_ENV}"
if [ "$expected" != "prod" ] && [ "$expected" != "test" ]; then
  echo "✗ verify-env FAIL: arg must be 'prod' or 'test' (got: $expected)" >&2
  exit 1
fi

url="$SITE_URL"
if [ -z "$url" ]; then
  echo "✗ verify-env FAIL: SITE_URL unset in .env" >&2
  exit 1
fi

pass=0
fail=0
check() {
  if [ "$2" = "ok" ]; then
    echo "  ✓ $1"
    pass=$((pass + 1))
  else
    echo "  ✗ $1"
    fail=$((fail + 1))
  fi
}

# Use a short timeout — we're not waiting for the world.
CURL_BASE=(curl -sS --max-time 10 -L)

echo "── verify-env: $expected @ $url ───────────────────────────────"

# 1. HTTP 200
HTTP_CODE=$(curl -s -o /dev/null -w "%{http_code}" --max-time 10 "$url/" || echo 000)
if [ "$HTTP_CODE" = "200" ]; then
  check "HTTP 200 on /" ok
else
  check "HTTP 200 on / (got $HTTP_CODE)" fail
fi

# 2. /robots.txt
ROBOTS=$(curl -s --max-time 10 "$url/robots.txt" || echo "")
if [ "$expected" = "test" ]; then
  if echo "$ROBOTS" | grep -q "Disallow: /"; then
    check "/robots.txt returns Disallow: /" ok
  else
    check "/robots.txt returns Disallow: /" fail
  fi
else
  if echo "$ROBOTS" | grep -q "Disallow: /"; then
    check "/robots.txt does NOT return Disallow: /" fail
  else
    check "/robots.txt does NOT return Disallow: /" ok
  fi
fi

# 3. X-Robots-Tag header on /
if [ "$expected" = "test" ]; then
  HEADER=$(curl -sI --max-time 10 "$url/" 2>/dev/null | grep -i "x-robots-tag" || true)
  if echo "$HEADER" | grep -qi "noindex"; then
    check "X-Robots-Tag header has noindex" ok
  else
    check "X-Robots-Tag header has noindex" fail
  fi
else
  HEADER=$(curl -sI --max-time 10 "$url/" 2>/dev/null | grep -i "x-robots-tag" || true)
  if echo "$HEADER" | grep -qi "noindex"; then
    check "X-Robots-Tag header does NOT have noindex" fail
  else
    check "X-Robots-Tag header does NOT have noindex" ok
  fi
fi

# 4. meta noindex in HTML
HTML=$(curl -s --max-time 10 "$url/" || echo "")
if [ "$expected" = "test" ]; then
  if echo "$HTML" | grep -qi 'name="robots" content="noindex'; then
    check "HTML meta robots has noindex" ok
  else
    check "HTML meta robots has noindex" fail
  fi
else
  if echo "$HTML" | grep -qi 'name="robots" content="noindex'; then
    check "HTML meta robots does NOT have noindex" fail
  else
    check "HTML meta robots does NOT have noindex" ok
  fi
fi

echo
if [ "$fail" -eq 0 ]; then
  echo "✓ verify-env PASS  ($pass checks)"
  exit 0
else
  echo "✗ verify-env FAIL  ($fail of $((pass+fail)) checks failed)"
  exit 1
fi
```
