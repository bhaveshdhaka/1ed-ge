# Ingest (PDF/CSV/Image → trades) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A daily drag-and-drop import ritual in the admin day screen: the owner drops trade screenshots / CSVs / PDFs, the AI parses + dedupes + groups the fills into positions, attributes them to internal accounts (asking the owner to confirm unknown account links once), and the owner approves each trade before it lands in the day record.

**Architecture:** A new `src/lib/ingest.ts` core pipeline (normalize → parse → attribute → group → dedupe) fed by a new auth'd `POST /api/admin/ingest` endpoint; a review-queue UI in the DayWorkspace; an apply step that merges approved positions into `days/<hkt-date>.md` and persists platform-id→internal-id aliases as `platformIds[]` on account records. PDF text is extracted with `pdftotext` (poppler) and parsed by a cheap model — `deepseek/deepseek-v4-flash-0731` (`AI_MODEL_INGEST`) — exactly as the owner directed; CSVs use a deterministic Tradovate parser (validated against the owner's real exports in `/tmp/opencode/import-demo/`); images use the existing vision path. Source files are ephemeral — decoded to text, never saved.

**Tech Stack:** Astro 5 SSR API routes, React 19 admin (DayWorkspace), `gray-matter`/`fs` content writes (`src/lib/content.ts`), poppler-utils (`pdftotext`) in the container, OpenRouter (`orChat`) for the cheap-text + vision parses.

## Global Constraints

- **Cheap model ONLY for PDF/CSV text parsing** — `AI_MODEL_INGEST` default `deepseek/deepseek-v4-flash-0731` (owner-directed; librarian-verified exact OpenRouter ID, $0.09/$0.18 per 1M, 1M context, `structured_outputs`). Images keep the existing vision model (`AI_MODEL_VISION`). Never the expensive vision model for text.
- **Ask before linking to an account.** Unknown platform id → propose + the owner confirms ONCE (persisted as `platformIds[]` on the account record); never silently guess. Every parsed trade sits in a review queue — the owner approves/edits/discards each.
- **Dedup is per-account.** The two accounts copy-trade the same strategy (near-identical fills) and must NOT collapse; each account's CSV+PDF are the same data and must import once. Fingerprints are per-account.
- **Group fills → positions.** ~30 per-fill round-trips ≈ ~4 ideas. The journal must not look like overtrading.
- **Ephemeral sources.** Files are base64 in the request, decoded, parsed, discarded. Never saved, never public.
- **Day record is the spine; R via `ROf`/`riskOf`** — ingest writes price-based `points` (long: `exit − entry`), `executions[{account,size}]`, market WITHOUT contract suffix (`MNQU6` → `MNQ`).
- **Repo has no unit-test runner.** Per-task verification = `npm run typecheck` (controller runs centrally — do NOT run while another task builds; astro races on `node_modules/.astro`) + targeted read-back; controller builds once per wave. Final task deploys + verifies live.
- **Commit only your own files** (`git add <exact paths>`, never `git add -A`; autosave cron may have uncommitted `src/content/market-news/*.md` edits — exclude them; never stage `.env`).
- **No two agents build at once.** Waves are write-disjoint; controller typechecks/builds centrally.

```ts
/** Tiny deterministic CSV parser: handles quoted fields, commas, CRLF. */
export function parseCsv(text: string): string[][] {
  const rows: string[][] = []
  let row: string[] = []
  let cur = ''
  let inQ = false
  for (let i = 0; i < text.length; i++) {
    const c = text[i]
    if (inQ) {
      if (c === '"') { if (text[i + 1] === '"') { cur += '"'; i++ } else inQ = false }
      else cur += c
    } else if (c === '"') inQ = true
    else if (c === ',') { row.push(cur); cur = '' }
    else if (c === '\n' || c === '\r') {
      if (c === '\r' && text[i + 1] === '\n') i++
      row.push(cur); cur = ''
      if (row.some((f) => f.trim() !== '')) rows.push(row)
      row = []
    } else cur += c
  }
  if (cur !== '' || row.length) { row.push(cur); rows.push(row) }
  return rows
}

export function decodeDataUrl(dataUrl: string): { mime: string; buf: Buffer } {
  const m = /^data:([^;]+);base64,(.+)$/.exec(dataUrl)
  if (!m) throw new Error('expected a base64 data URL')
  return { mime: m[1], buf: Buffer.from(m[2], 'base64') }
}

/** pdftotext -layout; throws a clear error if poppler is missing. */
export function pdfToText(buf: Buffer): string {
  const tmp = path.join(os.tmpdir(), `ingest-${Date.now()}-${Math.random().toString(36).slice(2)}.pdf`)
  fs.writeFileSync(tmp, buf)
  try {
    return execFileSync('pdftotext', ['-layout', tmp, '-'], { encoding: 'utf8' })
  } catch {
    throw new Error('pdftotext failed — is poppler-utils installed in the container?')
  } finally {
    fs.rmSync(tmp, { force: true })
  }
}
```

- [ ] **Step 2: HKT time conversion**

Tradovate timestamps are America/Chicago (`MM/DD/YYYY HH:mm:ss`); the site's day clock is HKT. Convert with Intl (DST-aware):

```ts
export function ctToHkt(ct: string): string | null {
  const m = /^(\d{2})\/(\d{2})\/(\d{4}) (\d{2}):(\d{2}):(\d{2})$/.exec(ct)
  if (!m) return null
  const [, mo, d, y, h, mi, s] = m
  // Parse as America/Chicago via Intl round-trip (deterministic, DST-aware)
  const parts = new Intl.DateTimeFormat('en-US', {
    timeZone: 'America/Chicago', year: 'numeric', month: '2-digit', day: '2-digit',
    hour: '2-digit', minute: '2-digit', second: '2-digit', hour12: false,
  }).formatToParts(new Date(`${y}-${mo}-${d}T${h}:${mi}:${s}:00Z`))
  const get = (t: string) => parts.find((p) => p.type === t)?.value ?? ''
  const asUtc = Date.UTC(Number(get('year')), Number(get('month')) - 1, Number(get('day')),
    Number(get('hour')) % 24, Number(get('minute')), Number(get('second')))
  return new Date(asUtc).toISOString()
}
```

(The Chicago-local wall time is recovered by asking Intl what UTC instant produces that wall time when rendered in Chicago; the date is then exact. Hour-24 edge is guarded with `% 24`.)

- [ ] **Step 3: Tradovate deterministic parsers**

```ts
/** Performance CSV → fills (validated against /tmp/opencode/import-demo). Columns:
 * symbol,_priceFormat,_priceFormatType,_tickSize,buyFillId,sellFillId,qty,buyPrice,sellPrice,pnl,boughtTimestamp,soldTimestamp,duration */
export function parsePerformanceCsv(rows: string[][]): Fill[] {
  const out: Fill[] = []
  for (const r of rows) {
    const [symbol, , , , buyFillId, sellFillId, qty, buyPrice, sellPrice, pnl, boughtTs, soldTs] = r
    if (!symbol || !/^[A-Z]/.test(symbol)) continue
    out.push({
      symbol, qty: Number(qty) || 1,
      buyPrice: buyPrice ? Number(buyPrice) : null,
      sellPrice: sellPrice ? Number(sellPrice) : null,
      buyTime: boughtTs ? ctToHkt(boughtTs) : null,
      sellTime: soldTs ? ctToHkt(soldTs) : null,
      pnl: parseUsd(pnl),
      buyFillId: buyFillId || undefined,
      sellFillId: sellFillId || undefined,
    })
  }
  return out
}

/** '$(29.00)' / '$0.50' → signed number. */
export function parseUsd(s: string): number {
  const neg = /\(/.test(s)
  const n = parseFloat(s.replace(/[^0-9.]/g, ''))
  return (Number.isFinite(n) ? n : 0) * (neg ? -1 : 1)
}

/** Orders CSV → account-keyed rows. Column 'Account' carries the platform id. */
export function parseOrdersCsv(rows: string[][]): { orderId: string; platformId: string; symbol: string; price: number; qty: number; time: string | null }[] {
  const out = []
  for (const r of rows) {
    const [orderId, account, , side, contract] = r
    if (!orderId || !/^[A-Z0-9]/.test(orderId)) continue
    const price = r[7] ? Number(r[7]) : null        // avgPrice
    const qty = r[8] ? Number(r[8]) : 1             // filledQty
    const time = r[9] ? ctToHkt(r[9]) : null        // Fill Time
    if (!account || !price) continue
    out.push({ orderId, platformId: account, symbol: contract, price, qty, time, side: side?.trim().toLowerCase() })
  }
  return out
}
```

```ts
async function llmJson<T>(system: string, userText: string, model: string, maxTokens = 2000): Promise<T | null> {
  const raw = await orChat([{ role: 'system', content: system }, { role: 'user', content: userText }], model, true, maxTokens)
  const cleaned = raw.trim().replace(/^```(?:json)?\s*/i, '').replace(/```$/, '').trim()
  try { return JSON.parse(cleaned) as T } catch { return null }
}

/** Performance PDF text → fills (cheap model, owner-directed). */
export async function parsePerformancePdfText(text: string): Promise<Fill[]> {

    symbol: String(f.symbol ?? ''),
    qty: Number(f.qty) || 1,
    buyPrice: f.buyPrice != null ? Number(f.buyPrice) : null,
    sellPrice: f.sellPrice != null ? Number(f.sellPrice) : null,

    sellTime: f.sellTime ? ctToHkt(String(f.sellTime)) : null,
```

- [ ] **Step 5: Attribution + alias resolution**

```ts
function stripContract(symbol: string): string {
  return symbol.replace(/[A-Z0-9]{2,3}$/, '').toUpperCase() || symbol.toUpperCase()   // 'MNQU6' → 'MNQ'
}

export function resolveAlias(platformId: string, accounts: IngestCtx['accounts']): { internalId: string | null; candidates: string[]; suggested: string | null } {
  const known = accounts.find((a) => (a as { platformIds?: string[] }).platformIds?.includes(platformId))
  if (known) return { internalId: known.id, candidates: [], suggested: null }
  const candidates = accounts.map((a) => a.id)
  return { internalId: null, candidates, suggested: candidates[0] ?? null }
}
```

Attribution: build an `orderId → platformId` map from all Orders rows; for each fill without a platformId, look up `buyFillId`/`sellFillId`; if the batch had no Orders file (or the id is still missing), leave `platformId` unset (→ alias confirm). Orders rows that carry an account the alias map doesn't know flow into `platformIdsSeen`.

- [ ] **Step 6: Group fills → positions (deterministic time clustering)**

```ts
const CLUSTER_GAP_MS = 10 * 60 * 1000   // 10 min gap starts a new position

export function groupFillsToPositions(fills: Fill[], account: { internalId: string | null; platformId: string | null; confirmed: boolean }): PositionProposal[] {
  const sorted = [...fills].sort((a, b) => (a.buyTime ?? a.sellTime ?? '').localeCompare(b.buyTime ?? b.sellTime ?? ''))
  const clusters: Fill[][] = []
  let cur: Fill[] = []
  let prev: string | null = null
  for (const f of sorted) {
    const t = f.buyTime ?? f.sellTime
    if (!t) { cur.push(f); continue }
    if (prev && Date.parse(t) - Date.parse(prev) > CLUSTER_GAP_MS) { if (cur.length) clusters.push(cur); cur = [] }
    cur.push(f); prev = t
  }
  if (cur.length) clusters.push(cur)
  return clusters.map((c) => {
    const totalQty = c.reduce((s, f) => s + f.qty, 0)
    const buys = c.filter((f) => f.buyPrice != null)
    const sells = c.filter((f) => f.sellPrice != null)
    const entry = buys.length ? buys.reduce((s, f) => s + (f.buyPrice ?? 0) * f.qty, 0) / buys.reduce((s, f) => s + f.qty, 0) : 0
    const exit = sells.length ? sells.reduce((s, f) => s + (f.sellPrice ?? 0) * f.qty, 0) / sells.reduce((s, f) => s + f.qty, 0) : entry
    const direction: 'long' | 'short' = entry <= exit ? 'long' : 'short'
    const points = direction === 'long' ? exit - entry : entry - exit
    const start = c.find((f) => f.buyTime ?? f.sellTime)?.buyTime ?? c[0]?.sellTime ?? ''
    const end = [...c].reverse().find((f) => f.sellTime ?? f.buyTime)?.sellTime ?? start
    return {
      market: stripContract(c[0]?.symbol ?? ''),
      direction, entry: round2(entry), exit: round2(exit), points: round2(points),
      size: totalQty, start, end, fillCount: c.length,
      fingerprint: `${stripContract(c[0]?.symbol ?? '')}|${direction}|${round2(entry)}|${round2(exit)}`,
      dup: false,
      account,
    }
  })
}
```

- [ ] **Step 7: Dedup + `ingestFiles` orchestration**

Dedup rules: per-account fingerprints; a proposal is `dup` when the batch already produced an identical fingerprint for the SAME account, or the day's `existingTrades` contain the same `market|direction|entry|exit` (rounded). `dupes` = count of dup proposals (they stay listed but pre-flagged; the owner can still approve — dedup is advisory).

`ingestFiles(files, ctx)`:
1. For each file: PDF → `pdfToText` → try `parseOrdersPdfText` first (if it yields platformIds, it's an Orders file) else `parsePerformancePdfText`; CSV → `parseCsv` → match header against known Tradovate headers → `parsePerformanceCsv` / `parseOrdersCsv` / `parseUnknownCsv`; image → `parseImage`.
2. Separate orders rows (platformId) from performance fills.
3. Attribute performance fills to platformIds via fill-id join against orders; collect `platformIdsSeen`.
4. Group all fills per platformId (unattributed fills form one "unknown" group).
5. Resolve aliases per platformId; unattributed → single alias proposal (candidates = all accounts, suggested = first).
6. Mark dups against `ctx.existingTrades` + within-batch per account.
7. `date` = the HKT date (from the earliest fill's ISO, sliced) — if no fills, today's HKT date.

```ts
export const prerender = false

export const POST: APIRoute = async ({ request }) => {
  if (!authorized(request)) return error('unauthorized', 401)
  const body = await request.json().catch(() => ({}))
  const files: IngestFile[] = Array.isArray(body.files)
    ? body.files.filter((f: unknown) => f && typeof (f as { dataUrl?: unknown }).dataUrl === 'string' && typeof (f as { name?: unknown }).name === 'string')
    : []
  if (!files.length) return error('no files provided')
  // ctx: internal accounts (id + platformIds + contract) from the accounts dir
  const accounts = listAccountCtx()   // see Step 2
  const existing = body.date ? (readEntry('days', `${String(body.date)}.md`)?.data.trades as unknown[]) ?? [] : []
  try {
    const result = await ingestFiles(files, { accounts, existingTrades: existing as never })
    return json({ ok: true, result })
  } catch (e) {
    return error(e instanceof Error ? e.message : 'ingest failed')
  }
}
```
