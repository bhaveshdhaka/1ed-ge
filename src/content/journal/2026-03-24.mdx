# read the trends, then fix the input

Spent an hour on the performance page reading the correlation table. The headline: my screen time and my losses are linked tighter than I wanted, and my best months all correlate with quiet time streaks.

That's not mystical — it's the input/output table of my own behaviour. When the input is clean, the output is clean. I'm changing one input at a time and watching the correlations move.
